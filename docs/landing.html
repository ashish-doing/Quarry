Not Just Claimed — Verified

SAFETY YOU CAN
ACTUALLY TEST.

Every safety system here was physically tested, not just implemented. This is the one axis of this build with zero hand-waving.

Command-Loss Watchdog

✓ VERIFIED

If the link to the companion laptop drops, the robot stops itself — independently, with zero dependency on cloud reachability.

Tested by killing the control process mid-drive and timing the stop: 0.5s response, confirmed live.

CollisionGuard

✓ VERIFIED

An independent proximity cutoff on the ESP32 — physically separate from the Pi's decision-making, so a software fault upstream can't disable it.

Two independent safety layers, not one — this is a deliberate redundancy design, not an accident.
Multiplayer, Done Honestly

NOT PUBG.
MISSION CONTROL FOR REAL ROBOTS.

There's no shared virtual world here — each Field Agent's robot lives in their own real room. What's shared is the session, the leaderboard, and the verification, not the physical space.

🤖 Field Agent

Has their own UGV hardware. Their robot patrols their own real space, reporting into the shared Hub. They retain full, exclusive control over their own robot — always. Nobody else can drive it.

👁 Spectator

No hardware needed. Join with a callsign, watch any connected site's feed, vote Confirm/Dispute, chat with the squad — zero install, zero setup.
